# MANIAC CITY

A browser-based 3D open-world action game prototype built with Vite, TypeScript, and Three.js.

## Features
- 3D city environment with roads, intersections, buildings, streetlights, and traffic-like vehicles
- Third-person player movement with walking, sprinting, jumping, and interaction
- Vehicle entry, driving, and exit mechanics
- Basic combat, wanted-level system, police chase behavior, and mission flow
- HUD with health, cash, mission objectives, and minimap
- Main menu, settings, pause menu, and local save support

## Run locally

1. Install dependencies:
   npm install

2. Start the dev server:
   npm run dev

3. Open the local Vite URL shown in the terminal (typically http://localhost:5173)

4. To produce a production build:
   npm run build

## Controls
- WASD: move
- Shift: sprint
- Space: jump / handbrake while driving
- E: enter/exit vehicles or interact
- Left mouse button: fire
- R: reload
- Esc: pause menu
- Mouse: camera aiming

## Current status
This is a playable prototype focused on the first core loop: explore the city, enter a vehicle, complete missions, earn money, and see the wanted system respond in-world.
